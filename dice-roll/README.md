# 차곡 · 주사위 굴리기 (두 번째 미니게임)

실행: Game 폴더에서 `node dice-roll/preview.cjs`, 브라우저에서 http://127.0.0.1:4176/dice-roll/ 접속.
본게임: http://127.0.0.1:4176/number-tiles/ . 기존 4175 본게임 서버도 새로 실행하면 연결됩니다.

- 독립 테스트 지갑은 3,000점으로 시작하며 본게임 저장소와 분리됩니다. 하단에서 테스트 점수를 충전할 수 있습니다.
- 주사위를 누른 후 스와이프, 방향 버튼 또는 방향키로 이동합니다. 숫자 키 1·2·3으로 선택할 수 있습니다.
- 중앙 가로 세 칸, 30/45/60초는 사용자 조정값이며, 5/2/1배는 기존 테스트 설정을 유지합니다.
- 시작 전 문제를 숨기고, 실제 24방향 회전 및 모서리 축 CSS 3D 굴림을 사용합니다. 40개 시드 고정 문제는 역재생 검증 후 사용합니다.
- 수식 클리어 후 타이머와 주사위를 동일 가중치로 추첨합니다. 기존 타이머 규칙은 유지합니다.
- IndexedDB 공통 지갑, BigInt 정산, 중복 이벤트 차단, 탭 소유권, 시작 후 중단 실패를 재사용합니다. 이동 완료는 입력 +180ms 기준으로 판정합니다.
- 소리는 기본 꺼짐이며 플레이 화면에서 켤 수 있습니다.

검증: `node dice-roll/test.cjs`, `node number-tiles/integration.test.cjs`, `node number-tiles/test.cjs`.
실제 IndexedDB 회귀 테스트: http://127.0.0.1:4176/number-tiles/integration-tests.html .

남은 플레이테스트: 실제 휴대폰의 스와이프 감각, 60초 난이도 및 지급률. 로컬 저장은 서버 기반 부정행위 방지가 아닙니다. 강제 종료 복구는 실패 정산되며 종료 이벤트가 실행되지 않은 경우 이동 진행도는 복원되지 않습니다.

시간 설정 변경은 새 문제와 아직 베팅하지 않은 기회에 적용됩니다. 이미 시작한 판과 정산 결과는 기존 설정을 유지합니다.
