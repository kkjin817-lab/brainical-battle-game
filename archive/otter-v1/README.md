# 수달의 조개 쟁탈전 · Otter Creek

브라우저에서 `index.html`을 열면 실행되는 1인용 아케이드 프로토타입입니다. 빌드나 설치가 필요하지 않습니다. 최신 Chrome / Edge 권장. 인터넷 연결 없이도 게임이 실행되며, 온라인에서는 웹폰트를 사용합니다.

## 플레이

- 방향키 ← → 또는 A / D: 이동. 가까운 조개는 자동으로 집습니다.
- Space: 던지기. 누르고 있으면 연속 발사합니다. 이동 중에는 비스듬히 던집니다.
- Shift: 배로 받아치기. 약 0.5초 동안 활성화되며 재사용까지 2.5초입니다.
- P / Esc: 일시정지. 다른 창으로 이동해도 자동으로 멈춥니다.
- 마우스: 경기장에서 좌우 이동, 왼쪽 버튼을 누르고 있으면 던지기, 오른쪽 클릭으로 배치기.
- 터치: 경기장을 드래그하며 던지거나 화면 아래 버튼을 함께 사용합니다.

아래쪽 주황 머플러 수달을 조작합니다. 중앙선을 넘은 조개는 상대편 소유가 됩니다. 날아오는 조개에 맞으면 잠깐 움직일 수 없습니다. 놓친 조개는 자기 쪽 수거 줄에 모입니다. 조개가 0개인 상태를 3초 유지하면 즉시 승리합니다. 60초 종료 시 조개가 더 적으면 승리, 같으면 무승부입니다.

중앙 구간에는 8초마다 좌우가 바뀌는 물살이 있습니다. 경기 시작 전 AI 난이도 3단계를 선택할 수 있습니다(넓은 화면의 오른쪽 패널). 소리는 상단 버튼으로 켤 수 있습니다.

## 구조

- `index.html`: 화면과 안내 문구
- `style.css`: 반응형 레이아웃, 색상, 타이포그래피
- `game.js`: Canvas 렌더링, 입력, AI, 충돌 및 승리 판정
- `game.js`의 `THEME`: 테마 색상
- `game.js`의 `RULES`, `LEVELS`: 게임 규칙과 난이도
- `drawOtter`, `drawShell`, `drawWater`: 캐릭터 / 아이템 / 경기장 그림. 테마 교체 시 이 함수를 바꾸면 됩니다.

그림은 Canvas 도형으로 직접 그리며 외부 게임의 이미지·음원을 사용하지 않습니다. 효과음은 Web Audio로 합성합니다. 현재는 재미와 조작을 확인하기 위한 프로토타입이며 온라인 대전과 진행 저장은 없습니다.
