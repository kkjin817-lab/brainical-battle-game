# 차곡 · 위험한 금고 — 다섯 번째 미니게임

Game 폴더에서 `node risky-vault/preview.cjs` 실행 후 http://127.0.0.1:4179/risky-vault/ 에 접속합니다.
본게임: http://127.0.0.1:4179/number-tiles/ . 기존 4175 서버는 재시작하면 새 모듈을 제공합니다.

## 플레이

- 3×4 금고에 보물 9개와 폭탄 3개. 시간 제한 없이 선택합니다.
- 보물 1/2/3/4/5개에서 각각 1/1.5/2/3/5배입니다. 마지막 배당 하나만 원금 포함 지급합니다.
- 보물 뒤에는 ‘받고 종료’ 또는 ‘하나 더 열기’를 고릅니다. 계속을 누른 뒤 다음 금고를 고르기 전에도 종료할 수 있습니다.
- 첫 개봉 전에는 지급 종료가 없습니다. 폭탄이면 지급 0점, 보물 5개면 5배 자동 종료합니다.
- 남은 금고·보물·폭탄과 다음 폭탄 확률을 표시합니다. 금고 위치에 따른 사전 확률 차이는 없습니다.
- 앱 이탈·새로고침 후 같은 배치와 진행을 복원합니다. 다른 네 미니게임의 중단 실패 정책은 그대로 유지합니다.
- 독립 테스트 지갑은 3,000점으로 시작합니다. 본게임 지갑과 분리되며 하단에서 테스트 점수를 충전할 수 있습니다.
- 본게임에서는 다섯 미니게임이 각각 20% 확률로 등장합니다. 기존 주사위 30/45/60초, 순간 기억 4초 공개 설정은 유지합니다.

## 저장과 정산

기회 생성 때 배치를 고정합니다. 선택 시 금고 결과·진행을 먼저 IndexedDB에 저장하고, 성공한 뒤 약 350ms 개봉 연출을 실행합니다. 폭탄 또는 다섯 번째 보물은 선택과 지급까지 같은 트랜잭션에서 정산합니다.
저장에 실패하면 결과를 보여주지 않고 같은 선택 이벤트를 재시도할 수 있습니다. 개봉 연출 중 재접속하면 저장된 보물을 표시하고 DECIDING으로 복원합니다. SELECTING·DECIDING은 그대로 복원하고 SETTLED는 재지급하지 않습니다.
버전 번호와 이벤트 ID로 개봉/지급 동시 요청을 직렬화합니다. 1.5배는 정수 분자 3 / 분모 2와 BigInt로 계산해 큰 점수도 정확하게 처리합니다.
예: 1,076점에서 500점 베팅, 보물 2개 종료 → 지급 750점, 잔액 1,326점, 다음 최대 베팅 1,300점.

자동 검증은 고정 배치와 별도 임시 저장소를 사용합니다. 순수 로직, 모든 배당, 폭탄, 복원, 설정 스냅샷, 큰 정수, 저장 실패 시 비공개, 동일 이벤트 재시도, 동시 개봉/지급, 터치 잠금을 검증합니다.
3열×4행·시간 제한 없음·중단 복원·20% 등장 비율은 PRD의 프로토타입 제안을 적용했습니다. 배당은 초기표 그대로이며 향후 플레이테스트 후 조정합니다. 실제 휴대폰 조작감은 추가 확인이 필요합니다. 로컬 저장 내용 분석과 조작을 막는 서버 검증은 포함하지 않습니다.
