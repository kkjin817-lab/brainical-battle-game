# 차곡 · 반대로 터치 — 네 번째 미니게임

Game 폴더에서 `node reverse-tap/preview.cjs` 실행 후 http://127.0.0.1:4178/reverse-tap/ 에 접속합니다.
본게임: http://127.0.0.1:4178/number-tiles/ . 기존 4175 서버는 재시작하면 새 모듈을 제공합니다.

## 플레이

- 그대로: 화살표와 같은 방향. 반대로: 화살표와 반대 방향.
- 준비 3초 후 10문제에 도전합니다. 문제당 1초, 정답 후 250ms 피드백입니다.
- 고정된 방향 버튼 또는 방향키로 답합니다. 누른 채 유지하거나 드래그하면 추가 답변으로 처리하지 않습니다.
- 첫 오답·시간 초과에 종료합니다. 10개 성공 5배, 7~9개 2배, 5~6개 1배, 0~4개 0배입니다. 배당은 원금 포함입니다.
- 앱 이탈은 성공 개수와 무관하게 0배입니다. 결과에서 실패한 규칙, 화살표, 선택과 정답을 확인합니다.
- 독립 테스트 점수는 3,000점으로 시작하며 본게임 지갑과 분리됩니다. 하단 버튼으로 테스트 점수를 충전할 수 있습니다.
- 본게임에서는 네 미니게임이 각각 25% 확률로 등장합니다. 주사위 30/45/60초와 순간 기억 4초 공개 설정은 유지합니다.

## 구현과 검증

`engine.js`에 정답 매핑, 균등 문제 생성, questionId별 입력 판정, 시간 경계, 배당과 응답 기록 재검증을 분리했습니다. `CONFIG`의 시간·배당을 기회마다 스냅샷으로 저장합니다.
QUESTION/FEEDBACK 상태를 공통 IndexedDB 저장 흐름에 연결하며, 차감·지급의 원자성, BigInt 점수, 다중 탭 소유권을 재사용합니다. 시작 이후 복구는 중단 실패입니다.
문제 타이머는 렌더링 프레임에서 시작합니다. 1,000ms 입력은 유효하며 1,000ms 초과는 미응답 시간 초과입니다. 마감 때 150ms 동안 큐에 남은 입력을 확인하며 이벤트 시각으로 판단합니다. 피드백 동안 입력은 저장하지 않습니다.
저장·렌더링 지연으로 피드백이 길어질 수 있으나 다음 문제는 항상 새 1초를 제공합니다. 결과에 응답 시간, 규칙 전환 수, 반대로 문항 수, 최대 프레임 간격과 입력 처리 지연을 기록합니다.

```
node reverse-tap/test.cjs
node number-memory/test.cjs
node dice-roll/test.cjs
node number-tiles/integration.test.cjs
node number-tiles/test.cjs
```

브라우저 테스트: http://127.0.0.1:4178/reverse-tap/tests.html
공통 저장 회귀: http://127.0.0.1:4178/number-tiles/integration-tests.html

문제당 1초·250ms 피드백·배당·25% 등장 확률은 PRD의 초기 테스트 설정입니다. 실제 휴대폰의 1초 체감 난이도와 입력 감각은 추가 플레이테스트가 필요합니다. 강제 종료 시 진행 중 응답은 복원되지 않으며 0배로 정산합니다. 서버 검증이나 공식 순위는 포함하지 않습니다.
