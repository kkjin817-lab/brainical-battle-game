# 차곡 · 순간 기억 — 세 번째 미니게임

Game 폴더에서 `node number-memory/preview.cjs` 실행 후 http://127.0.0.1:4177/number-memory/ 에 접속합니다.
본게임은 http://127.0.0.1:4177/number-tiles/ 입니다. 기존 4175 서버도 재시작하면 새 모듈을 제공합니다.

독립 테스트 점수는 3,000점이며 본게임 지갑과 분리됩니다. 하단 버튼으로 3,000점을 추가할 수 있습니다.

## 규칙

- 3초 준비 → 1~9 위치를 4초 공개 → 숫자를 동시에 가림 → 15초 동안 1부터 순서대로 터치.
- 첫 오답에서 종료합니다. 맞춘 칸 재터치는 무시합니다.
- 9개 정답 5배, 7~8개 2배, 5~6개 1배, 0~4개 0배. 원금 포함입니다.
- 시간 초과는 정답 개수로 정산하지만 시작 후 앱 이탈·새로고침은 0배입니다. 조기 정산 버튼은 없습니다.
- 결과 화면에서 전체 배치와 맞춘 칸·틀린 칸을 확인할 수 있습니다.
- 본게임에서는 타이머·주사위·순간 기억을 각각 1/3 확률로 선택합니다. 주사위의 30/45/60초 설정은 유지합니다.

## 구현 및 검증

`engine.js`에 배치 검증, 편향을 제거한 Fisher–Yates 셔플, 상태 전환, 정답 판정, 입력 기록 재검증, 배당 계산을 분리했습니다. 설정은 기회마다 저장합니다.
공통 IndexedDB 지갑과 BigInt 점수를 사용하며 COUNTDOWN/MEMORIZE/RECALL의 중단 복구와 원자적 차감·정산을 지원합니다.
가린 셀은 텍스트와 접근성 이름에서 정답을 제거합니다. 공개 시간을 실제 렌더링 전환에 맞춰 기록하며 `actualRevealMs`, `maxFrameMs`, `longFrameCount`를 결과에 남깁니다.
답변 마감 때는 150ms 동안 대기 중인 입력 이벤트를 확인하며, 입력 이벤트 시각으로 15초 경계를 판정합니다.

검증 명령:

```
node number-memory/test.cjs
node dice-roll/test.cjs
node number-tiles/integration.test.cjs
node number-tiles/test.cjs
```

브라우저 테스트: http://127.0.0.1:4177/number-memory/tests.html
공통 저장 회귀 테스트: http://127.0.0.1:4177/number-tiles/integration-tests.html
테스트 페이지는 별도 임시 저장소와 고정 배치를 사용합니다.

최초 숫자 공개 시간은 사용자 요청에 따라 4초로 설정했습니다. 단계별 시간 단축은 추후 추가하며, 현재 모든 단계는 4초입니다. 15초 답변·배당·세 게임 등장 비율은 기존 설정을 유지합니다. 실제 휴대폰 터치감과 난이도는 추가 플레이테스트가 필요합니다. 로컬 데이터나 외부 촬영을 이용한 부정행위를 방지하는 서버 검증은 포함하지 않습니다. 종료 이벤트 없이 프로세스가 종료되면 실패로 복구하며 진행 중 정답 개수는 복원되지 않습니다.

기존 준비 중인 기회는 새로고침 시 배치를 유지한 채 4초 설정을 적용합니다. 이미 시작한 판과 정산 결과의 설정은 유지합니다.
